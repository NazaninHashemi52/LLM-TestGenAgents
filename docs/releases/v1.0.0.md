# v1.0.0 — Team release (June 2026)

The first complete version of the framework, built as a 4-person team
project at Politecnico di Torino (March–June 2026). This tag marks the
codebase as it stood at the end of that project.

## What's included
- **Three test generation strategies:** single-agent, competitive
  multi-agent (adversarial / diversity / coverage), and collaborative
  multi-agent with specialized roles.
- **LLM abstraction layer** for Ollama, Groq, Gemini, and OpenRouter.
- **Evaluation** of coverage, mutation score, and test diversity, plus an
  aggregation script that builds a comparison table.
- **Example results** on the `calculator` module (see README).

## Known limitations
- Only one Code Under Test module (`calculator`).
- Results are stored per strategy, so runs on different modules overwrite
  each other.
- The example results were measured before the last calculator edge-case
  tests were added.

## What's next
v2.0.0 is in development. It adds multi-module evaluation, CI, and unit
tests for the framework. See [CHANGELOG.md](../../CHANGELOG.md).
